# 40 — Skills d'interface

## Fait

Quatre skills sont installés pour préparer le vrai écran : `frontend-design` (Anthropic), `ui-skills-root` et `improve-ui` (UI Skills), et `bm-design-system` (système Tailwind v4, React).

Ils sont dans `.cursor/skills/` du projet et dans le dossier personnel `skills` de Cursor.

## Pourquoi

Le frontend temporaire doit être repris avec une direction visuelle, un routage vers le plus petit skill utile, un audit d'interface, et un système de composants compatible avec Tailwind 4.

## Fichiers

`.cursor/skills/frontend-design`, `.cursor/skills/ui-skills-root`, `.cursor/skills/improve-ui`, `.cursor/skills/bm-design-system`. Le dossier `.cursor/` reste ignoré par Git.

## Vérification

Chaque dossier contient un `SKILL.md` dont le champ `name` correspond au dossier.

## Ensuite

Construire l'écran réel en s'appuyant sur ces skills. Le dépôt Git ne les transporte pas : `.cursor/` est ignoré.
